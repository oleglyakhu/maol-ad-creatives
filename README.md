# MAOL Ad Creatives — Claude Skill

Скилл для Claude, который пишет тексты рекламных креативов (статика и видео) по стандартам агентства MAOL.

## Что внутри

- `SKILL.md` — сама инструкция для Claude: обязательный процесс перед написанием (сбор материалов → анализ аудитории/ниши → боли → подтверждение → тексты), структура креативов, стандарты стиля.
- `references/static-examples.md` — примеры реальных статических креативов по нишам.
- `references/video-examples.md` — примеры реальных видео-сценариев по нишам.

## Установка

1. Скачай этот репозиторий (Code → Download ZIP) или отдельно файл `.skill`, если он приложен в релизах.
2. Открой Claude.ai, начни новый чат.
3. Прикрепи `.skill`-файл (или запакуй папку заново — см. ниже) как вложение к сообщению.
4. Нажми **Save skill** на появившейся карточке.

## Как запаковать в .skill заново после правок

Если редактируешь `SKILL.md` или файлы в `references/`, скилл нужно перепаковать перед раздачей команде — команда `package_skill.py` из official skill-creator упаковывает папку в единый `.skill`-файл для установки.

## Лицензия / использование

Внутреннее использование агентством MAOL.
